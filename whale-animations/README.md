# 小鲸桌宠动画集 · 2026-11-03 尺寸修正版

本导出直接使用当前正式桌宠资产，不含被拒绝的降噪/重绘试验。不包含桌宠程序或 Codex 图集。

每套分为 basic（基础）、transitions（入退场）、emotions（情绪）三个独立ZIP。全部解压到同一目录即可汇合；也可只下载需要的动作。
每个动作包含原样透明PNG逐帧、preview.png（APNG动画）和timing.json。APNG请在支持动画PNG的浏览器或播放器打开，某些看图软件只显示第一帧。

画布384×384，不作AI放大；APNG保持RGBA、原始帧时长。循环动作无限循环，单次动作播放一次后停在最后一帧；单次APNG不会自动切换待机，应用需按timing.json自行调度。
工作和睡眠：enter → loop（任意循环次数）→ exit。exit复用enter反向帧，不是新增原画。情绪/挥手单次后可切idle。
工牌装左右移动为小跳，非写实步行。图像文件只表示原地姿势；应用的横向位移、拖动、菜单等不包含在动画文件中。
情绪尺度修正已经应用；少量头身比例/轮廓差异、生成颗粒和帧间纹理变化仍存在，不能称完全无闪烁。Mac原生桌宠未验收。
